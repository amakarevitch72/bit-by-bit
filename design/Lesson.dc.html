A transistor is a switch you flip with electricity

Base ON → current flows Put voltage on the base and current passes from top to bottom. Remove it and the path is cut.
Two switches in a row Stack transistor A on top of transistor B. Current reaches the LED only if A and B are both on.

Your goal: wire two transistors so the LED lights only when A and B are both on. Test all 4 input combinations.

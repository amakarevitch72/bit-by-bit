LEVEL 2 · LESSON OR gate

Same two parts, a new rule

What you know In Level 1, stacked transistors needed both A and B before current could reach the LED.
The new rule Now the LED should light if A is on, if B is on, or if both are. Either switch must be enough.
A B LED 0 0 off 0 1 ON 1 0 ON 1 1 ON
Your goal: find a way to wire the same two transistors so either one can light the LED.

LEVEL 6 · LESSON Half adder

Making bits add up

Adding in binary There's no digit "2", so 1 + 1 carries to the next column.
A + B = C S 0 + 00 00 0 + 11 01 1 + 01 01 1 + 110 10
Two outputs, two chips S is the sum bit (the right digit), C the carry (the left digit). Each one is a gate you already built. From now on you build with chips: each counts as one block.
Your goal: find which chip makes S and which makes C, so A + B comes out right for all four inputs.
